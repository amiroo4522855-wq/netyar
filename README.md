## ✨ این چه اپی است؟

**کافی‌نت نت‌یار** یک اپلیکیشن وب دسکتاپی/موبایلی است که مثل یک کافهٔ اینترنت کار می‌کند:
می‌نشینی، از منو (۵۱۲ سایت واقعی و دسته‌بندی‌شده) سفارش می‌دهی و **با یک کلیک هم وارد سایت می‌شوی هم آدرسش را کپی می‌کنی**.

همه‌چیز در **یک فایل HTML خودکفا** (`netyar.html`) — بدون سرور، بدون فریم‌ورک، بدون تبلیغ. حتی آفلاین کار می‌کند (فقط جستجوی موزیک اینترنت می‌خواهد).

## 🚀 قابلیت‌ها

| بخش | توضیح |
|---|---|
| 🌐 **۵۱۲ سایت واقعی** | در ۲۵ دسته (جستجو، AI، بانک، بورس، کافی‌نت و پرینت و…) با توضیح فارسی |
| ⚡ **ورود آنی** | کلیک = بازشدن سایت در تب جدید + کپی همزمان آدرس |
| 🔍 **جستجوی زنده** | نتایج لحظه‌ای با هایلایت، سازگار با نیم‌فاصله و اعداد فارسی |
| 🎧 **پلیر موزیک واقعی** | جستجوی زنده در Audius (با سوئیچ خودکار هاست) و Internet Archive، پخش آنلاین، لینک مستقیم گوگل/یوتیوب برای هر نتیجه، شافل، تکرار، Media Session، اکولایزر واقعی |
| 💃 **رقص نور بیس-محور** | پس‌زمینه با انرژی بیس نفس می‌کشد و رنگ می‌چرخاند |
| 🎮 **۱۴ بازی کامل** | «دایی ناصر» (شب/روز ۱۳ ثانیه‌ای، صحرا/جنگل/رود، سختی فزاینده) + «برج‌سازی» + تتریس، ۲۰۴۸، مار، دوز، حافظه، سنگ‌کاغذ‌قیچی، ری‌اکشن، سکه، تاس، پازل ۱۵، واژه‌یاب و شطرنج — با رکورد روی دستگاه
| 🧮 **ماشین‌حساب دقیق** | اولویت استاندارد عملیات، درصد، جذر/مجذور/معکوس/π، دقت ۱۳ رقمی (بدون خطای اعشار)، تاریخچه، کیبورد فیزیکی + ارقام فارسی |
| 🎬 **لودینگ سه‌بعدی** | مکعب چرخان ۳بعدی با حلقه‌های ژیروسکوپی — ۱۰ ثانیه |
| ⭐ **علاقه‌مندی‌ها** | ذخیره روی دستگاه (localStorage) |
| ⌨️ **میان‌برها** | `/` جستجو · `Space` پخش/مکث · `↑↓` صدا · `←→` جلو/عقب · `1-6` ناوبری |
| 📱 **ریسپانسیو کامل** | سایدبار در دسکتاپ، نویگیشن پایین در موبایل |

## 🖥️ اجرا

هیچ نصبی لازم نیست:

```bash
# روش ۱: مستقیم باز کن
netyar.html را در مرورگر باز کن

# روش ۲: با سرور محلی
python3 -m http.server 3000
# سپس http://localhost:3000/netyar.html
```

## 🌍 انتشار رایگان (GitHub Pages)

1. ریپو را بساز و push کن (دستورات پایین 👇)
2. در ریپو: **Settings → Pages → Source: GitHub Actions**
3. تمام! آدرس زنده: `https://amiroo4522855-wq.github.io/netyar/`

*(ورک‌فلو آماده در `.github/workflows/pages.yml` هست و با هر push خودکار منتشر می‌کند.)*

## 📦 ساخت ریپو و push

```bash
# در github.com یک ریپوی جدید به نام netyar بساز (بدون README) بعد:
git remote add origin https://github.com/amiroo4522855-wq/netyar.git
git push -u origin main
```

## 🗂️ ساختار پروژه

```
├── index.html        ← نسخهٔ صفحات گیت‌هاب (خودکار از بیلد)
├── netyar.html       ← اپ کامل تک‌فایلی (خروجی بیلد)
├── src/
│   ├── shell.html    ← اسکلت HTML + لودینگ ۳بعدی
│   ├── style.css     ← تمام استایل‌ها (تم سرمه‌ای/طلایی)
│   ├── app.js        ← موتور اپلیکیشن
│   ├── icons.js      ← سیستم آیکون SVG (سبک Lucide)
│   ├── data1..9.js   ← دیتابیس ۵۱۲ سایت
│   ├── fonts/        ← وزیرمتن (در خروجی embed می‌شود)
│   └── build.js      ← اسکریپت مونتاژ تک‌فایل
└── .github/workflows/pages.yml
```

## 🔨 بیلد مجدد

```bash
cd src && node build.js
```
